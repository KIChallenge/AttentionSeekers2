## 3. General jury criteria (participation info, apply to both stages)

| Criterion                                    | Our answer                                                                                                                                                                                           | Demo moment                             |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Methodik, Daten- und KI-Qualität             | Positions fitted from dated Stellungnahmen and press, claim-level verification by a second model family, reference-class forecast with intervals, persona fidelity tested on held-out Stellungnahmen | Agent card, inspector, forecast card    |
| Nutzen und Wirkung                           | Prepares the Dachverband for real negotiations: simulate other institutions' likely positions, blockers and coalitions before a Begutachtung or Honorarverhandlung                                   | Setup room with a transfer template     |
| Umsetzbarkeit, Time-to-Impact                | Runs on a laptop with local Postgres and any OpenAI-compatible gateway; first use needs only the internal archive connector and an analyst in the loop; next three steps in README                   | README, closing slide                   |
| Transparenz, verantwortungsvoller KI-Einsatz | Every claim to a source passage, as-of slider, deliberation inspector, masked names, honest misses, stated limits                                                                                    | Inspector, archive, method page         |
| Nutzbarkeit, Kommunikation                   | Three disclosure levels, DE/EN, replay player, 3-minute desk path                                                                                                                                    | Dashboard, executive level              |
| Innovationsgrad                              | Game-theoretic coalition calculus over fitted positions, round learning record, backtest against a real reform, interconnected evidence archive                                                      | Coalition graph, lesson cards, backtest |

## 4. Submission checklist (participation info section 4)

- [ ] Code and run files in the assigned public team repo
- [ ] README: approach, run instructions, dependencies, configuration, known limitations and open points
- [ ] Methods and key technical decisions documented (link PRD, coverage matrix, method page)
- [ ] No keys, tokens, passwords, personal data, raw PDFs, unreleased documents (pre-push secret scan)
- [ ] Cached reference run committed so the demo works offline
